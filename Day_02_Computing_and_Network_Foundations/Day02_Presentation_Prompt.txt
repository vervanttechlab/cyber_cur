LEARNING OBJECTIVES (show these on Slide 2)
  1. Use basic Windows and Linux commands to check system, process and network information.
  2. Describe how LANs, WANs, routers, firewalls and DMZs are arranged in an organization.
  3. Explain IP addresses, ports, protocols and port forwarding.
  4. Explain how a web request travels from a browser to a web server and how it is logged.
  5. Read a simple script (Python / PowerShell) and explain what it does.
